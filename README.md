# Chapter06_Collections

This repository contains example code and notes for Chapter 6: Collections. The examples demonstrate common Python collection types and utilities (lists, tuples, sets, dicts, and the collections module).

Getting started

- Use Python 3.8+.
- Run example scripts directly, for example:
  ```bash
  python examples/example_list.py
  ```

Repository layout

- examples/    - sample scripts demonstrating collection usage
- src/         - (optional) library modules
- tests/       - (optional) tests
